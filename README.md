# 투맨피자 포장 주문

QR코드로 접속하는 **포장 전용 메뉴 선택 사이트**. 가게 정보(주소·전화·영업시간·배달)는 일절 없음.
손님이 장바구니에 담은 뒤 「직원에게 보여주기」 화면(한국어 크게 + 손님 언어 병기)을 직원에게 보여 주는 방식이며, 주문 전송·결제는 없다.

## 주소
- 고객: `index.html` (`#/` 메뉴, `#/item/:id`, `#/half-half`, `#/cart`, `#/show` 직원 확인 화면)
- 관리자: `admin/index.html` (메뉴 · 반반 · 옵션 · 데이터) — PIN은 `src/admin/config.js` (기본 1234)

## 실행
빌드 없음. 웹 서버로 열어야 한다(file:// 불가): `npm run serve` → http://localhost:8080
테스트: `npm test` (가격·주문 로직) / `python3 tests/e2e.py` (실제 브라우저 화면 흐름, playwright 필요)

## 구조
```
index.html, admin/index.html     진입 화면
data/                            메뉴·옵션·반반 규칙·포장할인·확인필요 목록(JSON)
src/shared/lib/                  가격 계산, 장바구니, 저장소, 데이터 로더 (고객·관리자 공용)
src/customer/                    고객 화면 (pages, components, styles)
src/admin/                       관리자 화면 (pages, overrides, config)
tests/                           price.test.mjs, e2e.py
```
- 가격 규칙: 피자 1판 = 기준가 + (반반이면 두 맛 추가금 합산) + 크러스트 + 토핑. 포장 할인은 한 주문에 1회만: 담긴 피자 중 L이 있으면 3,000원, M만 있으면 1,500원(가장 큰 피자 크기 기준). 사이드·음료·소스는 대상 아님.
- 첫 화면에서 언어(한국어·English·日本語·العربية·Tiếng Việt)를 고르고, 이어서 「돼지고기 메뉴 제외 / 상관없다」를 고른다(메뉴 위 "바꾸기"로 재선택). 제외하면 재료에 페퍼로니·베이컨·햄이 든 피자·반반 맛·토핑이 숨겨진다 (규칙: `data/diet-rules.json`, 불고기는 미확인이라 포함 안 함).
- 확인되지 않은 가격(`needs_check`/`conflict`)은 판매하지 않는다. 미해소 항목은 `data/verification.json`(15건) 참고.
- 관리자가 바꾼 가격·품절·반반 규칙은 브라우저(localStorage)에 저장되어 원본 JSON 위에 덮어쓴다. 서버로 바꿀 때는 `data.js`만 교체.

## 한계
- 관리자가 바꾼 가격·품절은 **그 기기의 브라우저에만** 저장된다. 손님 폰에는 반영되지 않는다(서버가 생기면 해결).
- 관리자 PIN은 보안 기능이 아니다(코드가 그대로 내려감).
- 메뉴 사진은 본사 CDN 주소이며 매핑이 육안 확인 전이다. 불러오지 못하면 이모지로 대체된다.

## 다국어
고객 화면만 5개 언어(한국어·English·日本語·العربية·Tiếng Việt)를 지원한다(관리자 화면은 한국어). 문구는 `data/i18n.json` 한 파일에 있다: `ui`는 화면 문구(키), `content`는 메뉴·옵션 이름·설명·재료(한국어 원문이 키). 번역이 없으면 한국어로 표시된다. 새 메뉴를 추가하면 `content`에 번역을 같이 넣는다. 번역은 직접 작성했으므로 매장 확인이 필요하다.

## 사장님용 구글 시트 연동
- 시트: 메뉴 / 옵션 / 반반 / 설정 / 번역사전 탭. 설정은 `data/sheet.json`.
- 한국어(이름·설명·재료)만 고치면 영어·일본어·아랍어·베트남어 열이 자동 채워짐 (번역사전에 있으면 그 번역, 없으면 구글 자동번역).
- 사이트는 접속할 때마다 시트를 읽음. 시트를 "링크가 있는 모든 사용자 - 뷰어"로 공유해야 함. 읽기 실패 시 마지막 성공본 → 내장 데이터 순으로 대체.
- 시트에서 행을 지우거나 판매 FALSE → 숨김. 새 행 추가 → 새 메뉴(피자는 크러스트·토핑 옵션 자동).
